Status: Accepted

The user supersedes the25-percent empirical-volume/deletion trial with a bounded geometric taper trial: preserve nominal dimensions through10degrees, then taper width and height toward the configured minima using quintic smootherstep through the configured admission maximum. This mode is explicit and separate from ADR-0070 empirical volume policies; historical settings/files are not reinterpreted. Pure immutable policy/engine arithmetic owns the mapping; native tools transform root intents and refreeze them. Scope is the current41-root source design; parented paths reject until separately supported.

For quantized actual section angle, t=clamp((angle−10)/(maximum−10),0,1), retention=1−t³(10−15t+6t²). New targets are minimum+(original−minimum)*retention for both width and physical height. Preserve XY centerline/floor, commandZ=floor+resolvedheight, zero physical overlap. Ordinary full stadium E and saved ratios are recomputed; no25-percent multiplier or old post-volume deletion is compounded. Existing nominal/actual numeric width, height, rate, profile and state gates remain. Supplemental retract/wipe1.6/1.0 remains.

This is a named engineering assumption, not measured physical calibration or a new optimal packing claim. Positive minimum dimensions necessarily leave a finite material change at hard admission exclusion; nonlinear derivatives do not eliminate that boundary. Exact source recovery, fresh contact/spill/future-material/motion certificates and actual Studio preview are required separately. Original table objective certificates remain pre-taper provenance; tapered coverage/error is diagnostic. No physical print is authorized by this decision.

Detailed formula, lattice/representation adjudication, empty/rejection handling, external physical-calibration limitations and tests are recorded in `docs/specs/nonlinear-geometric-dimension-taper-trial-review.md`.
