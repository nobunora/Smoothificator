# Records

Use this folder for short chronological milestone notes.

Write a record:
- after a major implementation phase;
- after a risky refactor;
- after a release/physical-print gate;
- after a useful blocker or specification revision.

Keep it concise and factual:
- changed files;
- why;
- commands/checks;
- results;
- limits;
- risks;
- next step.

Do not duplicate the implementation task record or canonical specification.
