Extend the same source-contour construction owner, not a second offset algorithm.
Optional immutable SourceJointDetour inputs identify an existing original contour
segment's START joint and an explicit positive source arclength locality_mm. No
index-zero, ring-ID or coordinate special cases. Default empty tuple preserves
all existing paths/receipts exactly. A joint is the exact equality of predecessor
end/current start; duplicate or absent identities reject. All construction is
before the single numeric freeze. Never take a frozen accepted path and edit it.

Construct offset miters and the declared initial short-edge regularization,
retaining original vertex identity. During initial regularization, protect each
requested original joint: remove the unprotected endpoint of a short edge, retain
the existing end-vertex priority when neither is protected, and reject when both
are protected. This opt-in rule applies only to explicit detours; empty-detour
construction is unchanged. At each selected retained joint,
replace that miter with the actual source joint, and add offset waypoints at the
requested source arclength before and after it. Walk the ORIGINAL source contour
in the appropriate direction; short incident source edges may be traversed in
full. Compute waypoint tangent/normal from the actual incident source edge and
the same inward-orientation convention. Floats propose only, serialized at
construction precision then XYZ-quantized. Bound walks/vertices/checks and reject
overlapping detour neighborhoods, vanished selected joints or ambiguous wrapping.
No unbounded neighborhood search or implicit automatic acceptance.

Run the declared deterministic short-edge/grid-duplicate regularization after
insertion, then the same exact simple-polygon/orientation/nonzero validation and
numeric emission owner. Record every waypoint/source edge/locality, joint
replacement and removed vertex with its origin. A requested joint must remain in
the final path; reject rather than silently dropping the defining detour. The
joint and its two declared locality waypoints are protected during post-splice
short-edge regularization: remove the unprotected endpoint, retaining the existing
end-vertex priority when both are unprotected; if both are protected reject.
This explicit rule preserves the locality witness and existing empty-detour
behavior, and reproduces the investigated trailing-original-vertex removal. All
settings/provenance participate in construction identity and complete proposal
serialization. Generated-vertex provenance must not pretend to be an original
source vertex index. Keep all original source segment identities unchanged for
subsequent contact queries.
