## Goal and minimum trial route

1. Print the existing one-degree-per-original-layer, 0..45-degree, left-control/right-supplement coupon as the current reference.
2. On one small 5 x 5 flat-top plate, compare commanded clearance above a real sliced top surface with deposited volume per path length. Select a reliable low-output operating point, rather than attempting to infer an absolute machine Z resolution from G-code decimal places.
3. Refine the same two variables only when the first grid does not resolve the choice. Otherwise proceed directly to a 5 x 5 small 1-degree/2-degree validation coupon grid, varying output scale and transition behavior with the first stage's lower limits fixed.
4. Verify the selected policy on one full 0..45-degree left-control/right-supplement coupon. Reuse the full specimen only for this final check or if its current physical results already establish the operating limits sufficiently well to skip an earlier stage.

The minimum additional route is one flat grid, one low-angle grid, and one full-angle check. A failed or boundary choice may require another bounded grid; no fixed number of prints guarantees identification. Do not repeat normal filament flow/temperature/pressure calibration if the current profile already works. Freeze material, nozzle, speed, temperature, fan, source-top construction, retraction, wipe, and path length during a two-variable experiment.

## What the first two variables actually mean

The first grid uses:

- h_cmd_mm: commanded nozzle Z minus the actual original sliced top Z, positive above the source, zero overlap/downshift. This is a commanded clearance, not a measurement of the deposited physical thickness.
- volume_mm3_per_mm: commanded material volume divided by positive-deposition path length. This is a cross-sectional volume equivalent, not an assertion about the actual physical width of an ultrathin bead.

These are independently controlled in the experimental fixture. Existing production geometry contracts must not be bypassed to represent them: the experiment needs an explicitly reviewed calibration representation and an independently conservative collision/material envelope. A mathematical stadium with width smaller than height is invalid; do not force arbitrary low-volume cells into that representation or label them certified physical rectangles.

Minimum Z is a useful operating clearance over the particular source top, not an absolute firmware/mechanical accuracy claim. First-layer squish and bed texture must not determine this experiment.

## Small fixture, labels and evaluation

Use 25 small tiles, provisionally 24 x 20 mm each on 26 x 22 mm pitch, about128 x108 mm overall; verify placement against the actual saved bed. A complete 52-mm-long angle specimen in every cell would exceed a 180-mm bed, so the initial experiment uses compact flat tiles. The low-angle stage uses cropped 1-degree and2-degree sections with unchanged source-layer height, not a scaled-down full specimen.

Each flat tile has the same genuinely sliced several-layer base/top construction, an untouched reference strip, and three equal 15-mm supplemental lines at fixed generous separation. Evaluate the middle10 mm; retain2.5 mm at each end to distinguish start starvation/end blobs. One line may run in the opposite direction to reveal direction/pressure dependence. Do not place variable test marks on the bed's first layer. Preserve source bytes and use approved state-restoring insertion/hop/retraction/wipe machinery.

Print h_cmd groups from low to high where the frozen chronology permits, and hop above all deposited material before cross-tile moves. Source order, actual material envelopes and restoration checks still decide admissibility; merely sorting by clearance does not prove tool clearance.

Underside identification occupies only the first nominal source layer: recessed, mirrored-in-model upright-readable-after-flipping text, depth exactly that first-layer thickness, with solid backing above it. A recessed mark avoids making the tile rest on raised text. Provisional two lines per tile: `A1 H.010` and `V.000150`, with run/stage ID on a shared border or an additional short line if space permits. Use robust strokes suitable for the saved .4-mm nozzle (provisionally .5-mm strokes and3-mm character height), then inspect the actual original slice. If all conditions do not fit legibly, enlarge the tile; a bare ID is not a substitute for the requested conditions. Show units and the full frozen settings in the UI/CSV. A small edge notch and top-facing row/column locator prevent rotation/left-right confusion. Do not reserve a different color/material just for labels.

The user chooses one cell as requested, plus an optional symptom: acceptable / excessive central ridge / discontinuous or missing center / end blob / start starvation / scraping or poor contact / no acceptable cell. The UI emphasizes continuous adhesion, smallest central ridge, and consistency across the three lines. End defects do not automatically count as excessive steady-state volume. A user's visual choice cannot by itself identify actual width or height; optional microscope/profilometer measurements may be attached.

## Deterministic refinement and symptom branches

For an interior selected index i on an axis with neighboring settings x[i-1], x[i], x[i+1], define the next search bounds by the adjacent midpoints in that axis's search coordinate. Use linear coordinate for clearance and log coordinate for strictly positive volume. In that coordinate let the bounds be lo/hi and the selected point be s; use the five settings [lo, (lo+s)/2, s, (s+hi)/2, hi], then transform back, quantize to supported source-independent numeric steps and remove duplicates. This keeps the selected point even when the original clearance spacing is nonuniform; do not claim globally equal spacing in that case. If quantization cannot produce five unique values, stop refining that axis and keep it fixed. Do not interpret the numeric grid as measured mechanical resolution.

At an outer selected index, expand that boundary instead of narrowing away the unknown optimum. Respect the experimentally reviewed minimum clearance and motion/volume limits; request an explicitly changed experimental range rather than silently crossing them. `No acceptable cell` expands or switches the experiment according to the reported symptom and never stores a forced winner. Stop repeated refinement after two rounds by default; propose another variable pair or measurements rather than indefinitely running grids. Retest the selected point on the next plate and, where space permits, one rotated-position duplicate to expose bed-position/thermal drift.

Branches, each varying exactly two quantities:

| Observation after center is acceptable | Next axes | Fixed quantities |
| --- | --- | --- |
| End blob only | supplemental retract distance x wipe distance | h_cmd, volume, speed, restart amount |
| Start starvation after end cleanup | restart compensation x restart speed | accepted retract/wipe, center volume/clearance |
| Good minimum deposition, poor1/2-degree fill | overall material scale x low-angle correction/transition parameter | minimum operating clearance/volume, end handling |
| Good low-angle result, high-angle ridge | taper-onset angle x taper curvature | low-angle scale and accepted high-angle endpoint |
| Reproducible high-angle disappearance | endpoint volume x endpoint clearance | accepted low-angle scale, taper family, end handling |

Current retract1.6 mm and wipe1 mm remain fixed during the first matrix. Do not double them again just because center output is high. Retraction and restart compensation are different variables; do not mechanically unretract more material on the test line when trying to suppress an end blob.

The1/2-degree matrix should test the source geometry/coverage/tiling with established micro-deposition limits. It cannot identify the best34..45-degree taper on its own. Final0..45-degree verification remains necessary. Use a continuous, anchored taper with an exact100% low-angle plateau and independently specified high-angle endpoint; once selected, only its onset/curvature vary in a taper grid, not25 unrelated per-angle policies. Keep the current empirical baseline until this experiment supplies a replacement, so a good25..30-degree band is not silently changed by a tail-only trial.

## Plugin flow and persisted experiment contract

Wizard: choose calibration stage -> show two axes/ranges/units and fixed source settings -> preview25 cells with underside labels -> generate reviewed sliced trial -> print -> click one grid cell and optionally a symptom -> preview proposed narrowed/alternate axes -> generate next trial. Printing remains an explicit user action; choosing a cell never starts a printer automatically.

Freeze each trial manifest before emission: run/stage/iteration, source/settings/material/nozzle hashes, pair of axes and units, all25 actual quantized conditions and model positions, static conditions, label text/depth, nominal versus final E/volume convention, predicted envelope assumptions, output identities, and all validation receipts. Append user selection/symptom/measurements as a separate result linked to the immutable run. Cache geometric planning by source and policy identity; numerical calibration changes require fresh numeric/motion/material checks, even when source geometry is reused.

Scope for this turn: design proposal only, plus attempted UI printing of the existing final specimen. Production settings/schema changes and new matrix G-code require implementation/review of this explicit experiment mode. No current global minimum or safety assertion is modified by this document.
