# Specifications

This directory contains versioned implementation-independent handoff contracts for GitHub/Codex work.

The canonical system behavior for Adaptive Sub-Edge remains in:
- ../SPECIFICATION.md
- Accepted ADRs under ../adr/
- ../DOCUMENT_CONTRACT.md for precedence

A handoff specification MUST reference the exact canonical specification/ADR revision it was derived from. Do not copy large technical sections here and create a second source of truth.

Use one file per coherent implementation/review change.

When ready for repository review, the specification PR may be labeled `codex-ready`.
