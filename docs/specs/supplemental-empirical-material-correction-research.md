## Material-model conflict requiring explicit acceptance

The current `freeze_supplemental_emission.py` (79–85) inverts actual formatted E to nominal stadium width and enforces .21..45 mm. A 50-percent correction generally violates that contract. For unchanged height h and nominal width w, the old model predicts `w_corrected = factor*w + (1-factor)*h*(1-pi/4)`. For w=.21,h=.08,factor=.5 it predicts about .11358 mm, below .21; for narrow tall designs it can predict width below height, outside stadium-model validity entirely. Passing corrected E through the old inverse or suppressing its rejection without a separately named semantics change would be incorrect.

Treat requested correction as empirical commanded-volume calibration: nominal geometry remains the design envelope used by lookup and geometric clearance audits, while actual deposited shape/contact/coverage after calibration is unverified. Report nominal dimensions and commanded-volume fraction separately. Neither a static HEIGHT/LINE_WIDTH tag nor Studio's diamond rendering measures the physical result. Do not call a nominal-envelope certificate proof of actual corrected bead width, contact or surface improvement; reduced material need not remain contained in a nominal envelope without an empirical assumption. Keep the existing standard freeze validator unchanged; introduce an explicit opt-in native empirical-emission DTO/adapter, retaining the original full-volume freeze as design provenance. Any production-printable semantics change requires canonical/ADR reconciliation, not an artifact-only weakening.
