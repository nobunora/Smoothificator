The wipe producer splits a double-valued retraction length using each segment's length divided by total wipe distance, then passes each negative dE through the ordinary extrusion writer. The extruder updates its internal unrounded double E/retracted state first. The formatter independently rounds each emitted axis using `std::round(v*10**digits)`; active E precision is5. A later ordinary retract targets the configured internal retraction amount; unretract uses internal retracted length plus restart-extra, rather than summing serialized negative E tokens. This explains why a fixed displayed restore0.8 can disagree with the exact sum of displayed wipe/retract E amounts. It also shows explicit optional extra-unretract behavior for a PETG/toolchange path; stationary positive E is not universally an ordinary restore.

For ideal real numbers whose unrounded negative terms sum exactly to the configured target and whose only errors are independent nearest decimal rounding, N times half an E quantum is a valid triangle-inequality bound. The inspected implementation uses binary64 length ratios, accumulated internal state, a final target/no-op decision, small-value suppression and optional extra unretraction. The exact ideal premises have not been proved for every supported producer path or the actual binary. A bound on closeness also does not independently distinguish a deliberate small prime from ordinary restoration. Therefore do not describe N-half-quantum as an authoritative producer guarantee or enlarge the accepted family with N alone.

Actual complete106-event evidence is stronger and narrower: resolved ordinary amount0.8, restore speed30 mm/s, zero resolved ordinary/toolchange restart-extra, inherited overrides, the one actual scoped PLA execution family, exact source/producer/settings identity, and complete preceding negative-chain provenance. The actual exact debts are ONLY `{0.79998,0.79999,0.8,0.80001}`; the raw restores are identically `G1 E.8 F1800`. Negative-chain counts range1–9. Every actual chain happens to satisfy the proposed ideal N-half-quantum inequality, but this is a diagnostic observation, not proof of its universal use. The one −0.00002 case has9 negative tokens. All moving negative-E terms must be proven to belong to the recognized WIPE sequence; standalone negative-E commands must match the supported ordinary retract role/parameter/feed contract. No positive prime may be relabeled by numerical proximity alone.

Recommended first implementation contract: accept only this explicitly reviewed pinned family and its exact approved chain witnesses (or equivalent explicit source-family evidence); preserve exact already-correct commands; derive repayment from sequential new debt. Reject arbitrary `−0.2` followed by `+0.8`, unknown/custom/extra-prime roles and any unreviewed debt/producer family. If implementation needs a generic rounding envelope, first amend the specification with its exact assumptions and a proof including binary arithmetic/formatter behavior, rather than silently promoting this source observation into that rule. No domain geometry bound or overlap gate changes.
