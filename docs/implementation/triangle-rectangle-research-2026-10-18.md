# 直角三角形の長方形近似：調査と定式化

2026-10-18。今回の範囲はアルゴリズム調査と解析。既存の経路生成器・Orca表示ファイルは変更していない。

## 調査結果

採用する問題は **対称差面積の最小化 (minimum symmetric-difference-area approximation)**。
三角形 T と長方形 R に対し、

```text
I = area(T ∩ R)
A = area(R)
E = area(T \ R) + area(R \ T) = area(T) + A - 2I
minimize E
subject to A - I <= A/2
```

はみ出しは長方形面積の半分以下、つまり I >= A/2 とする。
誤差を長方形面積で割った比率を最小化すると小さい内接長方形が有利になるため、
対象三角形を固定して埋め残しと超過の絶対面積を合計する。
この制約の50%は上限であり、50%まではみ出すように配置する指示ではない。

一次資料：Alt, Blömer, Wagener, *Approximation of convex polygons*, ICALP 1990,
pp. 703–716, https://doi.org/10.1007/BFb0032068 。出版社公開の要旨は、
凸多角形と軸平行長方形の対称差最小化を入れ子の二分探索で解くと説明している。
本文全体は未取得。この論文の一般解に今回の寸法・底面接触・50%制約が
そのまま含まれるとは主張しない。以下は今回の三角形用に独立して導いた式。

## 単一長方形の解析解

三角形の頂点を (0,0), (B,0), (B,H)、斜辺を z=mx, m=H/B とする。
長方形の底辺は段差床 z=0 に置き、右端は x=B に合わせる：

```text
R = [B-w, B] × [0,h]
0 < w <= B, 0 < h <= H
```

これは軸平行・床接触のモデル。上昇する三角形では固定寸法を右へ寄せるほど
重なりが増えるため、この固定は合理的である。寸法が外接箱を超えるケースや
上下に自由移動する一般長方形の最適性とは区別する。

q = max(0, h-H+mw) とすると、はみ出し面積は q²/(2m)。従って

```text
E(w,h) = BH/2 - wh + q²/m
```

q>0 の領域で偏微分を0にすると

```text
∂E/∂w = -h + 2(h-H+mw) = 0
∂E/∂h = -w + 2(h-H+mw)/m = 0
w* = 2B/3
h* = 2H/3
```

この領域のヘッセ行列は [[2m,1],[1,2/m]]、行列式3で正定値。
q=0 の内接領域では最大面積BH/4、最小誤差BH/4。
上の解の誤差BH/6の方が小さく、区分領域全体の最適解になる。
はみ出し面積BH/18、長方形面積4BH/9、はみ出し率1/8=12.5%。
したがって追加の50%上限も満たす。

幅 w を固定したときの最適高さは H-mw/2、つまりその幅区間の斜辺高さの中央値。
線形斜辺なので中央点の高さと一致する。単に各線を薄くしたり、Zを大幅に
下げたりする手順は不要。

## 今回の寸法例

理想的な段差高 H=0.20 mm、角度10度の場合：

| 項目 | 値 |
| --- | ---: |
| 三角形底辺 B=H/tan(10°) | 1.134256 mm |
| 最適な論理長方形幅 | 0.756171 mm |
| 最適な高さ | 0.133333 mm |
| 2本に等分した線幅 | 0.378085 mm |
| 論理長方形全体のはみ出し率 | 12.5% |
| 等分後の低い側の線のはみ出し率 | 25% |
| 等分後の高い側の線のはみ出し率 | 0% |

高さ0.05–0.18 mm、各線幅0.25–0.45 mmの既存制約を満たす。
これは理想三角形の計算例であり、実スライスの各段差寸法からの生成結果ではない。
長方形の分割は幾何形状を保つが、実押出の丸みは形状を変える。

## 制約付きソルバーと複数長方形への適用方針

1. 元幾何と段差床から対象三角形を作る。従来の0.05-mm候補を起点にしない。
2. 論理長方形幅を n 本の線で等分する場合、
   n*0.25 <= w <= n*0.45 と高さ0.05–0.18を制約にする。
   三角形幅から n の有限上限が得られる。
3. 各 n について E の区分二次式の停留点と制約境界を調べる。
   内接/交差の切替点も評価し、50%上限を面積で直接検査する。
   三角形外へ床や右端を移動させる場合は交差多角形面積から再計算する。
4. E が最小の長方形を選び、幅 w/n で等分する。
   50%上限は論理長方形全体だけでなく実際の各線の長方形にも検査する。
5. 高さの異なる複数長方形を選ぶなら、目的関数は
   area(T symmetric_difference union(R_i)) とする。
   長方形を1個ずつ貪欲に置く方法では全体最適を保証できない。
   位置候補を離散化する動的計画法はその候補集合内の最適解であり、
   連続最適性が必要なら区分式の境界・停留点解析、または保証付きの
   区間分枝限定を別途実装する。

比較として、制約なしで床から立つ k 個の隣接長方形に別々の高さを許す場合、
左の埋め残し幅 B/(2k+1)、各長方形幅 2B/(2k+1)、高さ 2iH/(2k+1)
(i=1..k) が得られる。誤差は BH/[2(2k+1)]。
k=2 なら高さ0.08と0.16 mmだが、各幅0.453703 mmは最大線幅0.45を超えるため、
そのまま実線として採用できない。寸法制約を入れて再最適化する必要がある。
本数無制限なら無制約モデルで誤差が0に近づくので、実際には最小線幅・高さや
明示的な本数制約を含めた解として扱う。
