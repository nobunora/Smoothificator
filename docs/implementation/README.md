# Implementation Records

This directory stores repository-review results and implementation evidence derived from an approved handoff specification.

These records are NOT a second source of product requirements.

If repository evidence shows the specification or ADRs are wrong/incomplete:
1. stop affected implementation;
2. record the conflict;
3. return to specification adjudication;
4. update canonical documents/ADRs;
5. repeat repository review.

Recommended naming:
`docs/implementation/<change>-task.md`

Use `TASK_TEMPLATE.md`.
